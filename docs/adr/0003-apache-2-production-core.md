# Keep the production core permanently Apache-2.0

OpenBoard's server, protocol compatibility layer, identity and authorization basics, audit/export, GitHub adapter, user interfaces, and deployment tooling will remain Apache-2.0, with sustainability coming from support, managed single-tenant hosting, and separately licensed enterprise add-ons. This maximizes trust, portability, and upstream compatibility, but permits competitors to host the same core and rules out later restrictive relicensing.
